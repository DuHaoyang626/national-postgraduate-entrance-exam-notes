# 🖼️ 嵌入 Embed（内嵌 / 转置）

> [!abstract] 本页内容
> 在 wikilink 前加一个 `!`，即可把目标内容**内嵌**到当前笔记，实现"一处书写、多处展示"，内容与源笔记实时同步。

## 一、嵌入整篇笔记

`![[项目Beta]]`

![[项目Beta]]

## 二、嵌入某个标题（段落）

`![[会议记录#关键决策]]`

![[会议记录#关键决策]]

## 三、嵌入某个块

`![[项目Alpha#^alpha-goal]]`

![[项目Alpha#^alpha-goal]]

## 四、嵌入图片

源文件位于 `Assets/` 目录：[[Assets/示例图片.svg]]

```markdown
![[示例图片.svg]]
![[示例图片.svg|200]]        # 指定宽度（等比缩放）
![[示例图片.svg|400x200]]    # 指定宽 × 高
```

![[示例图片.svg|240]]

> 常用尺寸写法：`|200` 只写宽度；`|640x480` 写宽×高；`|400` 后接别名亦可。

## 五、嵌入音频 / 视频 / PDF

```markdown
![[audio.mp3]]          # 音频
![[video.mp4]]          # 视频
![[document.pdf]]       # PDF
![[document.pdf#page=3]]      # 从第 3 页开始
![[document.pdf#height=500]]  # 指定嵌入高度
```

> 把音频/PDF 文件放进 `Assets/` 即可用同样语法嵌入。文档打开时会默认嵌入 PDF 预览。

## 六、嵌入列表（块级嵌入）

先给列表定义块 ID：

- 苹果
- 香蕉
- 橙子

^fruit-list

从任意笔记写 `![[05-嵌入Embed#^fruit-list]]` 即可嵌入这段列表。现在把它嵌入本页自身：

![[05-嵌入Embed#^fruit-list]]

## 七、嵌入 Bases（数据库视图）

`![[演示/项目数据库.base]]` —— 把 [[演示/项目数据库.base]] 的默认视图内嵌进来：

![[演示/项目数据库.base]]

## 八、嵌入网页

Obsidian 支持 `![[https://url]]` 在阅读视图中以 iframe 嵌入网页：

```markdown
![[https://obsidian.md]]
```

> 需要联网；部分网站禁止被嵌入。更精细的 iframe 写法见 [[03-HTML语法]]。

## 九、搜索嵌入（query 代码块）

在阅读视图会实时渲染搜索结果：

```query
tag:#项目
```

> 上面的代码块会把所有带 `#项目` 标签的笔记（如 [[项目Alpha]]、[[项目Beta]]）实时列出来。

## 十、外部图片链接

```markdown
![描述文字|300](https://example.com/image.png)
```

- `![[...]]` 只用于**库内文件**；外部图片用 `![](url)`。

## 注意事项

- 嵌入是**单向**的：被嵌入的笔记**不会**因此产生反链接；若需要反向关联，请同时用 `[[笔记名]]` 引用。
- 嵌入内容与源笔记**实时同步**，改动源笔记即更新所有嵌入位置。
