# ✍️ 普通 Markdown 语法

> [!info] 说明
> Obsidian 完整支持 **CommonMark** 与 **GFM（GitHub Flavored Markdown）**。本页演示所有通用语法，是后续所有 Obsidian 专属语法的基础。

## 标题

# H1
## H2
### H3
#### H4
##### H5
###### H6

## 强调与文字效果

- **加粗**（`**加粗**`）
- *斜体*（`*斜体*`）
- ***加粗斜体***（`***加粗斜体***`）
- ~~删除线~~（`~~删除线~~`）
- ==高亮==（`==高亮==`，Obsidian 扩展语法）
- `行内代码`（反引号包裹）
- <u>下划线</u>（HTML 语法，详见 [[03-HTML语法]]）
- H^2^O 上标、H~2~O 下标（`^上标^` / `~下标~`）
- 文字后面直接换行（行尾两个空格 + 回车 = 硬换行）

> 提示：需要以字面显示特殊字符时用反斜杠转义，例如 `\*不是斜体\*` → \*不是斜体\*。

## 列表

### 无序列表
- 项目一
- 项目二
  - 嵌套项目（缩进两个空格）
    - 更深一层
- 项目三

### 有序列表
1. 第一步
2. 第二步
   1. 子步骤 A
   2. 子步骤 B
3. 第三步

### 任务列表（Todo）
- [ ] 未完成的任务
- [x] 已完成的任务
- [x] 又一个已完成项

## 引用（Blockquote）

> 这是一段引用。
> 可以跨多行。
>> 引用可以嵌套。

### 引用中的列表

引用内用列表：**每一行都要以 `>` 开头**，嵌套层级用 `>` 后的缩进表达。

```markdown
> - 项目一
> - 项目二
>   - 子项目 A（缩进两个空格）
>   - 子项目 B
> - 项目三
```

> - 项目一
> - 项目二
>   - 子项目 A（缩进两个空格）
>   - 子项目 B
> - 项目三

有序列表、任务列表同样可行：

```markdown
> 1. 第一步
> 2. 第二步
>
> - [ ] 未完成
> - [x] 已完成
```

> 1. 第一步
> 2. 第二步
>
> - [ ] 未完成
> - [x] 已完成

> [!tip] 三个要点
> 1. **每行都要 `>`**：别只在第一行写 `>`，否则后续行会脱离引用。
> 2. **空行保持引用**：引用内需要空行时写单独的 `>`。
> 3. **缩进决定嵌套**：列表的嵌套层级写在 `>` 之后。
> Callout（[[06-Callout提示框]]）本质是引用，规则完全一致。

```
纯文本代码块
```

缩进式代码块（前面空一行 + 缩进 4 个空格）：

    def old_style():
        pass

## 脚注

这是一个带脚注的句子[^1]，这是另一个[^2]。

[^1]: 第一个脚注的内容。
[^2]: 第二个脚注的内容，支持 *格式*。

行内脚注：直接写^[这是行内脚注的内容]即可，无需编号。
