# 🏷️ 属性（Frontmatter）与标签（Tags）

> [!abstract] 说明
> **属性**写在笔记开头的 YAML 区块（`---` 包裹）中，是笔记的**结构化元数据**；**标签**则是全文任意位置可用的**分类标记**。两者都能被 [[演示/项目数据库.base]]、搜索与图视图利用。

## 一、属性（Frontmatter / YAML）

笔记最顶部、以 `---` 包裹的 YAML 块。当前笔记的 frontmatter 就是一份活示例（见本页开头）：

```yaml
---
title: 示例笔记
date: 2024-01-15
status: active
rating: 4.5
completed: false
due: 2024-01-15T14:30:00
tags:
  - 项目
  - 重要
aliases:
  - 别名A
  - 别名B
cssclasses:
  - wide-page
related:
  - "[[项目Alpha]]"
---
```

### 属性类型

| 类型 | 示例 |
|---|---|
| 文本 | `title: 标题` |
| 数字 | `rating: 4.5` |
| 复选框（布尔） | `completed: true` |
| 日期 | `date: 2024-01-15` |
| 日期+时间 | `due: 2024-01-15T14:30:00` |
| 列表 | `tags: [A, B]` 或换行 YAML 列表 |
| 链接 | `related: "[[项目Alpha]]"` |

### 三个默认属性

- `tags` —— 全文标签，参与搜索与图视图着色。
- `aliases` —— 笔记**别名**，链接时输入别名也能匹配（演示见 [[04-链接与反链接]] 第九节）。
- `cssclasses` —— 为当前笔记追加 CSS 类，可配合 CSS 片段做定制排版。

## 二、内联标签

正文任意位置写 `#标签` 即可：

- `#标签` 普通标签
- `#父级/子级` 嵌套标签（用 `/` 分层）
- `#tag-with-dash`、`#tag_with_underscore` 带连字符/下划线

> 标签规则：可包含字母、数字（不能是第一个字符）、下划线 `_`、连字符 `-`、斜杠 `/`（嵌套层级）。空格、标点不能出现在标签内。

示例段落：这是一个带 #示例 标签的段落。↑ 该标签会被搜索引擎收录。

## 三、正文标签 vs 属性标签

两种写法效果等价，都会被检索、聚合、图视图识别：

```markdown
正文里：#教程

frontmatter 里：
---
tags:
  - 教程
---
```

## 四、属性与标签的用途

- **聚合**：[[演示/项目数据库.base]] 通过 `file.hasTag("项目")`、`status == "active"` 等筛选笔记。
- **搜索**：`tag:#项目`、`file:项目Alpha`、`property:status` 等。
- **模板**：日记模板可用 `{{date}}`、`{{time}}` 占位符自动填充。
- **统计**：配合 Dataview 等社区插件，可按属性做表格、看板、统计图表。
